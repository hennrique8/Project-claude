# Omniroute Launch - Top 10 OpenCode Skill Repos

Este projeto contém os 10 repositórios de skills mais populares do OpenCode, instalados como git submodules.

## Skills Instalados

1. **Superpowers** (293k stars) - Framework de SDLC para agentes com skills completas
2. **Ponytail** (148k stars) - Reduz 54% de código gerado com pensamento YAGNI
3. **UI/UX Pro Max** (131k stars) - Design Intelligence para criar UIs otimizadas
4. **Graphify** (122k stars) - Transforma codebases em grafos queryáveis
5. **Caveman** (108k stars) - Compressão de linguagem, reduz 65% de tokens
6. **Addy Osmani Agent Skills** (99.4k stars) - Coleção de 600+ skills variadas
7. **Understand Anything** (84.3k stars) - Visão de raio-X de arquitetura de codebases
8. **Awesome Claude Skills** (75.7k stars) - Lista curada de 1000+ skills prontos
9. **Archify** (72.5k stars) - Cria diagramas de arquitetura em HTML interativo
10. **Impeccable** (71.7k stars) - Design language com 61 regras determinísticas

## Como Usar

Para clonar com submodules:
```bash
git clone --recurse-submodules https://github.com/hennrique8/project-claude.git
```

Ou inicializar submodules após clonar:
```bash
git submodule update --init --recursive
```

## Objetivo

Este repositório centraliza os melhores tools e skills para desenvolvimento de IA, análise de código e automação de desenvolvimento, preparando o terreno para o projeto Omniroute.
